using the selected arXiv perpetual non-exclusive distribution license.

the operative proposal. See the [root license](../LICENSE),
[scope](../LICENSES/SCOPE.md) and [file inventory](../metadata/license-scope.json).

code and documentation receive the later additional grant described there.
