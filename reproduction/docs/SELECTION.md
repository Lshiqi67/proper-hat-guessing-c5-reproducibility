# Selection and evidence boundaries

Included unchanged from the previous local candidate: the audited manuscript
PDF and TeX sources, its generated tables, the small original generator/import
closure and basic auditors, the bound-17 witness, the complete branch/terminal
catalogues, original evidence manifests, rights notice and authorship disclosure.
The saved four-color strategy is added from the research tree because the new
input auditor directly checks it. The nine original full evidence ZIPs remain
byte-identical, including groups and profile/pattern metadata needed to check
the actual encoding. No private Git history, credentials, user configuration,
third-party package tree, cache, or exploratory proof search is selected.

The 27 October fresh input-auditor source and FreshRup source are copied without
byte changes. `provenance/copied-files.json` records source-relative provenance,
size and SHA-256. `fresh-audit/selected-leaves.jsonl` preserves the actual new
full-run selection. Its `recorded_checker` and `checker_sha256` fields describe
the older generation-time catalogue provenance; they do not name the checker
executed by `tools/verify.py`. New replay reports explicitly record the fresh
checker source and compiled executable hashes.

Selected historical final/input/replay/source records are included for concise
orientation. The separate consolidated review ZIP is the complete record of
the two-stage review, with failed or limited tests and supplementary work kept
in their proper scope. The large certificates are in the nine evidence ZIPs,
not duplicated inside the compact review ZIP.

The new `tools/verify.py` is a path/integrity/build/replay adapter. Its mathematical
input-checking implementation is the unchanged fresh source. It checks exact
catalogue identity coverage against parent branches and all 51 restricted-growth
diagonal representatives. The replay coverage check compares sets and rejects
duplicates; the number of rows alone is never a full verification criterion.

No original source or evidence file is overwritten. No original SAT search,
external solver installation, public upload, repository visibility change,
or new licensing decision is part of this preparation.
