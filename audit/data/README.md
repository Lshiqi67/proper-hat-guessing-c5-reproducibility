# 两次审查的派生数据字典

本目录在 2026-10-27 整理已经完成的两次审查结果。这里只重算既有 JSON、JSONL、TSV 和测试输出，核对表间连接；没有重新运行 SAT、RUP 或大证书哈希检查。数学逻辑审阅没有新计算，程序与计算复核的实际完成范围见 `summary.json`。

## 文件与计数单位

| 文件 | 内容与口径 |
| --- | --- |
| `summary.json` | 两阶段范围、历史实际运行时间、新整理时间、主结果、来源及发表状态；公开 URL 和 DOI 均为空 |
| `weight-summary.json` 与 `.tsv` | 九档父数、细分父数、子输入数、最终叶数、新增步骤、删除行、空子句及逐叶时间和 |
| `leaf-audit.jsonl` 与 `.tsv` | 8613 条最终叶，连接原路径、输入/证明 SHA-256、计数向量、批次位置和本轮新重放结果 |
| `input-audit.jsonl` | 8757 个实际语义审计输入；其中 8613 个为采用末端，余 144 个恰为被细分的父输入 |
| `evidence-files.jsonl` | 17226 个采用 CNF/DRUP 的原路径、字节数、先前实际校验的哈希；本次整理没有复制这些大文件 |
| `test-summary.json` | 按测试套件分列范围、随机种子、期望接受/拒绝、活动版样本及失败/超时；各项不能混加为独立测试数 |
| `component-types.json` | 14 类计数组件的目标、条款数、辅助数、完整类型哈希与合法输入覆盖数 |
| `source-records.json` | 构建以上派生表时实际读取的来源文件、字节数和 SHA-256；整理起止内容一致 |

## 路径与标识

`original_*` 路径相对原 P001 研究根目录。`snapshot_*` 路径相对本审核包根目录，使用 `snapshot/research/` 保留原研究根相对层级。原始大证书不在紧凑审核包内，不应将 `original_cnf` 或 `original_proof` 误解为包内文件。另行整理的完整发表候选包可以携带全部证据 ZIP；其存在和恢复验证不由本脚本判断。

`leaf_id` 格式为 `weight/profile/case`，父编号补足三位；直接叶的 `case` 为 `direct`，JSON 字段 `case` 本身为空值。权重是特殊色总计数。`count_vector_cycle_order` 按玩家 `(1,3,5,2,4)` 排列，`count_vector_player_order` 按 `(1,2,3,4,5)` 排列。`batch` 从 0 到 7，`batch_row` 从 1 起。

`rup_additions` 包括实际经过检查的最终空子句。`checked_empty=true` 仅取自本轮八批实际输出；`deletion_records_parsed_and_ignored` 是严格解析但按主检查器策略不执行删除的记录数。忽略删除仍保留已经证明的原输入后果。`seconds` 是该叶本轮重放耗时；九档逐叶耗时之和不是并行墙钟时间。

## 避免混淆

- 主全量为同一冻结版 `FreshRup` 的 8613 叶、66403934 步和全部空子句。
- `FreshRupActive` 仅是补充源码测试、差分、接口及三份真实样本，不加入主全量总数。
- 旧/新检查器差分和主要随机测试的种子为 20261027；Active 补充差分的种子实际为 20261028。各套件分别保存，不笼统称为同一种子。
- 368 次公共调用中，340 次有既定接受/拒绝要求，28 次只是格式策略观察；不是 368 个互不相同的数学案例。
- 600 秒超时发生在先行单叶样本脚本；该样本流程未完成。另行无单叶限时的主全量后来完成，二者没有混写。
- 初次新输入审计因元数据标签错误失败，原报告和初稿保留；修复后从头运行的结果才列为通过。

`tools/build_data.py` 从研究根的原始报告生成本目录，拒绝覆盖非空 `data`。本包副本用于审阅与核对，直接重建需保留原研究路径或另行移植源定位。新整理只验证数据一致性，不使旧结论自动升级为外部审稿或形式化认证。
